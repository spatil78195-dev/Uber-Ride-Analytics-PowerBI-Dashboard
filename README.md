# Uber-Ride-Analytics-PowerBI-Dashboard
# 🚕 Uber Ride Analytics Dashboard | Power BI

An interactive **Uber Ride Analytics Dashboard** built using Microsoft Power BI to analyze ride bookings, revenue, ride status, customer ratings, driver ratings, distance and monthly performance trends.

## 🎯 Project Objective

The objective of this project is to transform Uber ride and booking data into an interactive business intelligence dashboard.

The dashboard provides a consolidated view of:

- Ride bookings
- Completed and cancelled rides
- Revenue
- Booking value
- Total distance
- Average distance
- Customer ratings
- Driver ratings
- Monthly booking trends
- Customer rating analysis

---

## 📌 Key KPIs

The dashboard tracks important business metrics including:

| KPI | Description |
|---|---|
| Completed Bookings | Total rides completed successfully |
| Lost Bookings | Bookings that were not completed |
| Revenue | Total revenue generated |
| Total Distance | Total distance travelled |
| Average Distance | Average distance per ride |
| Customer Rating | Average customer rating |
| Driver Rating | Average driver rating |
| Booking Value | Value generated from bookings |
